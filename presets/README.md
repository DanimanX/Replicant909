# Replicant909 Factory Presets & MIDI Patterns

This directory contains the 8 factory patterns of **Replicant909** exported in Standard MIDI File format (`.mid`).

Every file is a standard Type 0 MIDI file that plays back in any modern DAW (Ableton Live, Bitwig, FL Studio, Logic Pro, Cubase, Reaper) and carries embedded Replicant909 metadata (BPM, Shuffle, Accent settings).

## Pattern Roster:
1. `01_Classic_House.mid` (124 BPM) - Iconic 4-on-the-floor kick, off-beat open hi-hat, syncopated handclap.
2. `02_Detroit_Techno.mid` (132 BPM) - Relentless kick drive, tuned low/mid toms, ride cymbal groove.
3. `03_Acid_Jack.mid` (128 BPM) - Shuffled 16th hats (Groove Shuffle 3), accented rim shot and snare snaps.
4. `04_Hard_Groove.mid` (138 BPM) - Heavy kick boom, flam snare on backbeat, syncopated toms.
5. `05_Electro_Funk.mid` (126 BPM) - Broken kick rhythm, spacious reverb clap tail, heavy swing.
6. `06_Industrial_Rave.mid` (145 BPM) - Driven attack click kick, distorted snare rolls, crashing cymbals.
7. `07_Minimal_Techno.mid` (125 BPM) - Tight muted kick thud, subtle rim shot clicks, pristine hats.
8. `08_Synthwave_909.mid` (118 BPM) - Vintage 80s room clap reverb, punchy stereo toms.
